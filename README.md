# 左下角信息 (HUD Fields)

为《明日方舟：终末地》主界面左下角提供网络延迟与 UID 显示定制，支持独立控制可见性与自定义显示文本。

## 功能特性

- **独立开关控制**：可分别控制延迟数值、网络信号图标以及底栏 UID 的显示或隐藏。
- **自定义文本模板**：支持使用占位符自定义文字格式（如 `{ping}ms`、`UID: {uid}`），也支持填写固定文本。
- **即时生效**：在模组菜单中修改后即时刷新主界面，无需重启游戏。

## 配置选项

在游戏内按 `ESC` →「模组菜单」→「左下角信息」即可调整：

| 设置项 | 默认值 | 说明 |
|---|---|---|
| **显示网络延迟** | 开启 | 控制左下角延迟数值与信号图标可见性 |
| **延迟显示文字** | `{ping}ms` | 模板，`{ping}` 自动替换为当前实际延迟 |
| **显示 UID** | 开启 | 控制底栏 UID 文字可见性 |
| **UID 显示文字** | `UID: {uid}` | 模板，`{uid}` 自动替换为当前真实 UID |
